## Project Overview
The ATM Simulation System is a Java-based application designed to simulate basic ATM operations through a graphical user interface.

## Technologies Used
- Java
- Java Swing
- VS Code

## Features
- Balance Enquiry
- Cash Deposit
- Cash Withdrawal
- Transaction History
- Graphical User Interface

## How to Run
1. Install Java JDK.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Compile and run `ATMGUI.java`.
